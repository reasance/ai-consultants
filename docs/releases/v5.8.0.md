# Release v5.8.0

**Date:** 2026-10-28
**Type:** Minor — Artificial Analysis Intelligence Index v5 preset refresh
**Previous:** v5.7.0

## Highlights

- Opus 5.5 becomes the Claude default, with reproducible effort levels for each quality tier.
- Maximum uses Astra/max, premium uses Sol/max, and standard uses Sol/high for OpenAI.
- Explicit user effort settings remain authoritative across CLI and API transports.
- Cache entries are isolated by tier, including different efforts on the same Opus model.
- Fable and Terra remain available as opt-in models; provider coverage and token prices stay unchanged.

## What's New

The AA v5 review informed the panel choices. Claude maximum, premium and standard use Opus at max, xhigh and medium respectively. Economy retains Haiku and Luna with their existing default behavior. No general benchmark score is presented as a security-review qualification or as a repository cost forecast.

## Breaking Changes

Default/premium Claude now uses Opus instead of Fable. Explicit effort defaults also change for matching tier models. To keep a specific current model or effort, set `CLAUDE_MODEL`, `CLAUDE_REASONING_EFFORT` or `CODEX_REASONING_EFFORT`. Configure preserves intentional pins and unmarked Fable choices; it migrates the marked managed default.

## Upgrade Guide

```bash
npx ai-consultants version
```

For an existing cloned installation, pull the new release using its normal update path. Review any persistent effort override before selecting a tier: an explicit override wins. Switching tiers alone does not rewrite the persistent configuration.
