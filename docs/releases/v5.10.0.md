## What's New

### Qwen4 model and provider contract

The final model is `qwen4-max`; the separate preview is never substituted.
Canonical thinking levels are low/high/xhigh, default high. `max_quality`
requests xhigh only on the OpenAI-compatible API wire; an explicit effort wins.
Qwen Code owns CLI effort through its provider settings, so an API effort
variable is not presented as a per-request CLI control.

The model has 1,000,000 total context tokens and up to 262,144 combined
thinking/answer tokens, or 131,072 output tokens without thinking. Singapore
pay-as-you-go reference rates are USD 1.50/4.50 per million input/output
tokens. Token Plan credit consumption is separate, and local session totals
continue to disclose Qwen as unpriced rather than reporting credits as free.

## Breaking Changes

The main Qwen target changes to the final Qwen4 model, and Qwen4 cannot use
the legacy DashScope text-generation wire. Users migrating a generated old
default must deliberately configure a compatible endpoint, format and matching
key. Active explicit Qwen3.8 Max or Flash pins retain their legacy implicit
endpoint. Custom URLs and credentials are never silently repointed. Existing
`QWEN3_*` variable names and command selectors remain supported.

## Upgrade Guide

For npm distribution:

```bash
npx ai-consultants@5.10.0 --version
```

A fresh Token Plan API setup uses:

```bash
export QWEN3_USE_API=true
export QWEN3_MODEL=qwen4-max
export QWEN3_FORMAT=openai
export QWEN3_API_URL=https://token-plan.maas.qwencloudapi.com/compatible-mode/v1/chat/completions
export QWEN3_REASONING_EFFORT=high
```

Provide the matching Token Plan key privately in `QWEN3_API_KEY`; do not paste
it into issues or Git. Pay-as-you-go requires an explicit regional compatible
URL and its matching key. The output budget includes thinking and the answer.
For CLI configuration, append the documented final-model provider entry while
preserving other models and credentials. See [the Qwen recipe](../RECIPES.md#qwen-via-qwen-cloud-token-plan)
and [the model reference](../MODEL_BENCHMARKS.md).
