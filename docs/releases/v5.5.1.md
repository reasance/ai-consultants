# Release v5.5.1

**Date:** 2026-10-24
**Type:** Patch — the project now lives at reasance/ai-consultants
**Previous:** v5.5.0

## Highlights

- **New home: [github.com/reasance/ai-consultants](https://github.com/reasance/ai-consultants).** The repository moved from `matteoscurati` to the `reasance` organization. The old URLs redirect, so nothing you already have breaks.
- **The npm package points to the new repository.** Repository, homepage and issue links on npmjs.com now name `reasance/ai-consultants`.
- **Published from the new repository with provenance.** This version goes through npm Trusted Publishing from `reasance/ai-consultants`.

## What's New

### Repository links

Every link to the repository now uses `reasance/ai-consultants`:

- `package.json`: `repository`, `homepage` and `bugs`
- `scripts/install.sh`: the default clone URL and the `curl | bash` one-liner
- the `ai-consultants` help text, README, `docs/SETUP.md`, `SKILL.md` and the `/ai-consultants:help` commands for Claude Code, Codex and Gemini
- the upgrade instructions in earlier release notes

Author credits are unchanged.

### Existing installs

GitHub redirects `matteoscurati/ai-consultants` to the new address, so `git pull` in an existing clone keeps working. To point a clone at the new URL explicitly:

```bash
cd ~/.claude/skills/ai-consultants
git remote set-url origin https://github.com/reasance/ai-consultants.git
```

## Upgrade Guide

```bash
# npx (no install)
npx ai-consultants "question"

# git clone install
cd ~/.claude/skills/ai-consultants && git pull

# curl | bash install
curl -fsSL https://raw.githubusercontent.com/reasance/ai-consultants/main/scripts/install.sh | bash
```

No configuration changes required.
