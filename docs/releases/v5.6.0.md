# Release v5.6.0

**Date:** 2026-10-25
**Type:** Minor — Gemini on `agy` by model ID; the Claude API effort and the DashScope output cap now reach the request
**Previous:** v5.5.1

## Highlights

- **Claude API mode honours `CLAUDE_REASONING_EFFORT`.** It goes out as `output_config.effort`; before, API mode ignored it and the model default applied.
- **Qwen on DashScope caps its output** with `QWEN3_API_MAX_TOKENS` (default 16384), as the configuration already documented.
- **Gemini on `agy` is addressed by model ID** (`gemini-4-argon-high`, `gemini-3.8-flash-high`, `gemini-3.8-flash-low`), the IDs `agy models` lists. Display names keep working.
- **Every rate re-checked** on its provider's official page on 2026-10-25: no price changed.

## What's New

### Gemini model IDs on `agy`

| Tier | Before | Now |
|---|---|---|
| default, premium, maximum | `Gemini 4 Argon (High)` | `gemini-4-argon-high` |
| standard | `Gemini 3.8 Flash (High)` | `gemini-3.8-flash-high` |
| economy | `Gemini 3.8 Flash (Low)` | `gemini-3.8-flash-low` |

An authorized consultation by ID passed on 2026-10-25. Cost estimates and their caveats recognise both spellings.

### Claude API effort

With `CLAUDE_USE_API=true`, `CLAUDE_REASONING_EFFORT=low|medium|high|xhigh|max` is sent as `output_config.effort`. Unset leaves the model's own default. `none` and `minimal` are rejected before the request, because the Messages API has no such levels.

### DashScope output cap

On the default DashScope wire, Qwen requests now carry `parameters.max_tokens` from `QWEN3_API_MAX_TOKENS` (default 16384). A non-integer value is rejected before the request.

## Breaking Changes

None — this release is backwards-compatible. A configuration that names a Gemini display name keeps working; only unpinned managed defaults are moved to the ID. A Claude API run with `CLAUDE_REASONING_EFFORT=none` or `minimal`, which used to be ignored, now fails before the request.

## Upgrade Guide

```bash
# npx (no install)
npx ai-consultants "question"

# git clone install
cd ~/.claude/skills/ai-consultants && git pull

# curl | bash install
curl -fsSL https://raw.githubusercontent.com/reasance/ai-consultants/main/scripts/install.sh | bash
```

No configuration changes required. Run `ai-consultants configure` to move an unpinned Gemini display-name default to its ID.
