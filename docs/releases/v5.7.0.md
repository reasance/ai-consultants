# Release v5.7.0

**Date:** 2026-10-27
**Type:** Minor — optional GPT-6.1 Terra support
**Previous:** v5.6.0

## Highlights

- Select GPT-6.1 Terra explicitly with `CODEX_MODEL=gpt-6.1-terra`; existing model tiers stay unchanged.
- Migrate a retired GPT-5.6 Terra choice to the current Terra line.
- Catch unsupported reasoning effort before a request is sent, and estimate long-context costs correctly.

## What's New

### Optional Terra model

The rate catalog includes Terra at $1 per million input tokens and $5 per million output tokens at Standard short-context rates. Above 272K input tokens, the full request uses $2 input and $7.50 output per million tokens. Built-in rates retain optional-model pricing if the JSON catalog is unavailable.

For Terra, API mode accepts `none`, `low`, `medium`, `high`, `xhigh` and `max`; the consultant CLI wrapper accepts `low` through `max`. `minimal` is rejected in both paths, and CLI `none` is rejected. Leave the effort unset to preserve the transport default. Tool calling requires the Responses API; this consultant's API path uses Chat Completions for text generation.

The regression tests use fake CLIs and HTTP responses. They verify request contracts and cost calculations; no live Terra API consultation or comparative quality evaluation is claimed.

## Breaking Changes

None. Existing model tiers are unchanged. A retired GPT-5.6 Terra setting migrates to GPT-6.1 Terra through configure.

## Upgrade Guide

```bash
npx ai-consultants@5.7.0 version
```

For a git installation, pull the latest main branch in the ai-consultants checkout. For the curl installer:

```bash
curl -fsSL https://raw.githubusercontent.com/reasance/ai-consultants/main/scripts/install.sh | bash
```

To use Terra, select `CODEX_MODEL=gpt-6.1-terra` explicitly in your configuration. No configuration change is required to retain the current default models.
