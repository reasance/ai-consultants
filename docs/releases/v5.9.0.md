# Release v5.9.0

**Date:** 2026-11-15
**Type:** Minor — Fable 5.2, Gemini 4 Hydrogen e Carbon via CLI
**Previous:** v5.8.0

## Highlights

- Use Fable 5.2 for demanding Claude tiers and Hydrogen for everyday Google tiers.
- Select Carbon/high explicitly through Antigravity on an eligible Ultra/Enterprise account.
- Keep model pins, explicit efforts and personal configuration choices under user control.
- Keep Hydrogen economy effort, confidence escalation and cache identity consistent when all API tiers share one model ID.

## What's New

### Model tiers

Claude premium uses Fable 5.2/high and maximum uses Fable/max. Standard remains Opus 5.5/medium and economy remains Haiku 5.5. Fable 5.1 stays selectable. Claude Code must be 2.1.321 or later for Fable 5.2.

Google economy uses Hydrogen/medium, standard high, and premium/default maximum xhigh. CLI IDs are effort-specific; the API uses `gemini-4-hydrogen` with an explicit thinking level. Argon and Flash remain selectable.

### Carbon is an explicit CLI option

Set these configuration values before selecting `max_quality`:

```sh
GEMINI_FRONTIER_CLI_MODEL=gemini-4-carbon-high
GEMINI_USE_API=false
```

Carbon requires an enabled Ultra/Enterprise account and an exact requested ID in `agy models`. It is absent from the account inventory checked with agy 1.5.9 on November 15. An unavailable selection fails before dispatch. Carbon is never an automatic fallback and is not silently replaced during routing, escalation or synthesis. With the frontier selector empty, Google maximum stays Hydrogen/xhigh.

### Effort-aware API routing and cache

Economy and premium Hydrogen requests share a model ID. Economy now carries its own request-scoped effort; a low-confidence result can escalate to premium effort on that same ID. Explicit efforts remain authoritative. Cache identity includes the effective economy effort, so a previous answer at another effort cannot satisfy the request.

### Evidence and estimates

The generated model reference uses Artificial Analysis Intelligence Index v5.0.1, refreshed from all 741 API rows on November 15. Scores belong to their measured efforts. The relative band rule starts frontier at 56.6 and mid at 44.6; it does not qualify a reviewer for a particular repository.

AA weighted cost per benchmark task is distinct from provider token pricing and subscription invoices. Fable standard API token rates are $8/$40 per million input/output tokens. Carbon estimates use list rates conservatively; current promotional and future list rates are explained in the model reference. No new-model inference qualification is claimed by these offline checks.

## Breaking Changes

No command or configuration key is removed. Preset model choices change, as do marked managed defaults when configuration is regenerated. Active unmarked models, explicit effort settings and pins are preserved. A pinned retired model still follows the existing same-line migration policy.

## Upgrade Guide

Check the published CLI version without starting a consultation:

```sh
npx ai-consultants@5.9.0 version
```

Upgrade Claude Code to at least 2.1.321 before selecting Fable. Review your desired tier and run configuration explicitly when you want the managed defaults to follow the new release. Existing personal files are not rewritten by this release operation.

Use Carbon only through the explicit CLI selector above on an eligible account. Model context windows and provider long-decode features do not raise this client's configured output cap automatically.
