# Release v5.11.0

**Date:** 2026-11-25
**Type:** Minor — Gemini 4 Neon and Artificial Analysis v5.0.2
**Previous:** v5.10.0

## Highlights

- Gemini 4 Neon is available on Antigravity and the Gemini API as an explicit choice for complex work.
- The model reference uses effort-matched scores and benchmark costs from the November 25 Artificial Analysis v5.0.2 snapshot.
- Grok OAuth startup claims the lock owner atomically when concurrent calls begin.

## What changed

Set `GEMINI_MODEL=gemini-4-neon-high` or `gemini-4-neon-xhigh` with `GEMINI_USE_API=false` for the Antigravity CLI. The exact ID must appear in the account's `agy models` inventory. Set `GEMINI_API_MODEL=gemini-4-neon` with `GEMINI_USE_API=true` and `GEMINI_REASONING_EFFORT=high` or `xhigh` for the API. Hydrogen remains the everyday default.

Artificial Analysis v5.0.2 measures Neon at 59.8 for high and 61.5 for xhigh. The per-task figures in the model reference reflect the benchmark workload.

## Upgrade

Run `npx ai-consultants@5.11.0 configure` to configure the npm version or update an existing Git-based installation with its usual pull or install command. Your existing explicit model choices carry forward.
